PIC 101 — PROFESSIONAL ISSUES IN COMPUTING
CHED-Aligned Teaching-Ready HTML Course Pack

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Choose a topic and follow its lesson sequence from foundation to application.
4. Use Previous/Next, arrow keys, or the slide overview inside each presentation.
5. Select Full Screen for classroom presentation.

LESSON DESIGN
- Each presentation contains 17 focused student-facing slides.
- Lessons begin with the topic and its foundation.
- Important concepts are explained in complete, plain-language sentences.
- Relevant situations and examples connect concepts to computing practice.
- Guided analysis, class application, understanding checks, and summaries are included.
- Unnecessary numbered bullets were removed.
- The presentation design follows the TPCC 4 classroom style: a fixed 16:9 canvas that automatically scales to fit the available screen.
- Use Previous/Next, Left/Right arrow keys, Page Up/Page Down, or the navigation dots.
- Press O for the lesson overview and F for full screen.

COURSE STRUCTURE
Unit 1 — Professional Foundations and Ethical Reasoning (Weeks 1–4)
Unit 2 — Computing in Society, Privacy, Cybercrime, and Intellectual Property (Weeks 5–9)
Unit 3 — Workplace Policy, Security, Quality, Governance, and Emerging Technology (Weeks 10–14)
Unit 4 — Digital Responsibility, Professional Practice, and Integration (Weeks 15–18)

All files work offline. Presentations contain no teacher scripts.
